# Weather Data Analysis System

## Project Overview
A Python mini project that simulates weather readings for five cities, validates data, performs statistical analysis, forecasts temperatures, and generates weather alerts.

## Features
- Simulated weather data collection
- Data validation and quality control
- Average, minimum and maximum temperature
- Standard deviation, heat index and dew point
- Short-term temperature forecasting
- Rule-based weather alerts
- CSV and JSON report export

## Technologies Used
- Python 3
- Standard libraries: `math`, `random`, `json`, `csv`, `datetime`, and `typing`

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python weather_system.py
   ```

The program generates `weather_clean_data.csv` and `weather_report.json` in the current folder.
